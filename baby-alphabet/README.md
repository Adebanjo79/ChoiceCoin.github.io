# Baby ABC Flashcards (D–Z)

Soft, low-stimulation alphabet flashcards for babies ages **6–12 months**, matching a slow-paced ABC learning script.

## What’s included

- **24 square learning images** for letters **D–Z**, plus a calm **grand finale**
- One clear letter + one matching object per card
- Bright, high-contrast colors on soft pastel backgrounds
- Simple HTML viewer with large type, slow speech readout, and swipe/next controls

## How to use

Open `baby-alphabet/index.html` in a browser.

Tips for 6–12 months:

1. Show **one card at a time** for 10–20 seconds
2. Point to the big letter, then the picture
3. Repeat slowly: **“D… D is for Duck”**
4. Keep sessions short and calm

## Design notes

- Large rounded letterforms for early visual tracking
- Soft pastel scenes with bright object/letter contrast
- Minimal clutter for low visual stimulation
- Consistent square flashcard format
