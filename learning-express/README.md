# The Soft & Bright Learning Express

Gentle 5-minute learning scenes for babies ages **6–12 months**.

**Format:** 30 scenes × 10 seconds each  
**Style:** Soft 3D plush/felt texture, bold high-contrast colors, pastel backdrops, smiling faces

## Learning goals

1. **Numbers 1–5** with color-matched train cars
2. **Colors** — red, yellow, green, purple, orange
3. **Shapes** — circle, triangle, square, star
4. **Sounds & movement** — stop/go, quack, ding-dong, puff, chug
5. **Quiet recap** — calm bedtime wind-down

## How to use

Open `learning-express/index.html` in a browser.

- Tap **Play 5 min** for automatic 10-second scene pacing
- Use **Say it slowly** for parent-guided single-word repetition
- Jump by Act or scene number for short sessions

Tips for 6–12 months:

1. Keep sessions short and calm
2. Point to one object at a time
3. Repeat single words: *Train… Red… Circle… Stop…*
4. Prefer smiles, eyes, and simple cause-and-effect sounds
